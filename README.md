# Ricko Portfolio Starter

Fresh implementation based on the portfolio plan you pasted from Claude. It is **not the exact original Claude source**, because that source was not attached—only the implementation plan/status was shared.

## Stack
React + TypeScript + Vite + Tailwind CSS v4 + React Router.

## Routes
- `/` → `/id`
- `/id` → Bahasa Indonesia
- `/en` → English

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Cloudflare Pages
Build command: `npm run build`
Output directory: `dist`
